# Chotu

A ~181M-parameter English chat LLM built from scratch by two people, to learn how LLMs work, and run locally on laptops.

- `CLAUDE.md`: frozen decisions, rules, sync workflow (read first)
- `docs/PROGRESS.md`: where we are, who's on what, handover log
- `docs/DECISIONS.md`: changes to frozen decisions
- `docs/LEARNING.md`: shared learning notes
- `docs/PROJECT_SETUP.md`: how each of us sets up Claude with the same context
- `docs/COLAB.md` and `notebooks/colab_setup.ipynb`: running on Google Colab
- `docs/JARVIS.md`: Jarvis Labs GPU machines (setup, pause, costs)
- `notebooks/eda_data.ipynb`: end-to-end look at the training data (live, explained)
