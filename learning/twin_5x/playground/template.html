Talk to the Twins

Both 7M twins run right here in your browser: the one that read 140M tokens (7 Nov) and the one that read 700M tokens (11 Nov). Give them the start of a sentence and they both continue it, or paste any text and see which twin finds it less surprising. They only learned to continue web text, so treat them as text-continuers, not chatbots.

How it picks each word

Temperature: lower plays it safe, higher takes more risks. Repetition penalty: above 1 discourages words it already used (1 = off). Both twins get the same random seed, so differences come from what they learned, not luck.

What does each twin expect next?

Its top 8 guesses for the very next token after your prompt, with the probability it gives each one, before it writes a single word. ␣ marks a token that starts with a space, ↵ a line break.

Who finds this text easier?

Paste any English text. Each token is shaded by how surprised a twin was to see it (darker = more surprised). The score is bits per byte, the same exam score as on the dashboard: lower is better.

Both models are the real checkpoints from Hugging Face (twin-day/main step 2,136 and twin-day/main-5x step 10,681), stored as 16-bit numbers. The maths was checked against PyTorch: same predictions, logits within 0.0001.
